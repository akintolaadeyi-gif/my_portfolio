RedPenn AI: Chrome-Native Design Audits

Role: Full-Stack & Extension Developer

Tech Stack: Chrome Extension (Manifest V3), React, Vite, FastAPI, Vercel, Supabase, Anthropic Vision API

Overview & Problem

Fast product cycles make it easy for weak hierarchy, accessibility gaps, and generic design patterns to reach production unnoticed. RedPenn AI gives builders a real-time second opinion on webpage design directly inside the browser side panel.

Architecture

  • Client-Side Extension: Built with React and Vite using Manifest V3 to capture targeted viewport screenshots and DOM structure on demand.
  • Hosted API: FastAPI backend deployed on Vercel managing Anthropic Vision requests and structured output parsing.
  • Privacy Layer: Supabase/PostgreSQL handling anonymous telemetry via randomized local IDs and one-way hashing.
